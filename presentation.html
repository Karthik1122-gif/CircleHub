01 // Problem & Context

The Hyper-Connectivity Paradox

Why global social media platforms fail modern urban & suburban neighborhoods.

⚠️
The Real-World Problem
  • ❌ Algorithmic Outrage: Platforms like X and Facebook prioritize viral controversy over local offline cooperation.
  • ❌ Urban Isolation: Residents live within meters of each other for years without ever discovering shared hobbies or skills.
  • ❌ Toxic Ad-Driven Feeds: Existing apps (like Nextdoor) devolve into public complaint boards and spam marketing.
  • ❌ Data Exploitation: Traditional social networks monetize location and invasive personal tracking.
💡
The CircleHub Solution
  • ✅ No Algorithm, No Ads: Pure, focused community collaboration organized strictly around shared interests.
  • ✅ Action-Oriented Circles: Micro-communities dedicated to offline sports, coding clubs, study groups, gardening, and book circles.
  • ✅ Real Meetups & RSVPs: Verified dates, direct Google Maps directions, and one-click WhatsApp invitations.
  • ✅ Zero-Buffering Performance: Instant edge serverless execution eliminating slow loading screens.

06 // Module Deep-Dive

Auth Engine & Form Validation

Secure, responsive user onboarding with real-time feedback and non-blocking warmup.

Interactive Validation Pipeline
  • ✨ Zero-Buffering Form: Inputs are immediately editable upon page render without waiting for server status.
  • ✨ 5-Stage Password Strength: Evaluates uppercase, digits, symbols, and length (>= 6) with a dynamic colored UI progress bar.
  • ✨ Non-Blocking Pre-Warm: Calls wakeBackend() with a 2-second timeout in the background while the user types.
  • ✨ Visual Field State Icons: Green checkmarks and clear inline error hints for instant correction.
Security & Credential Protection
  • 🔒 Password Masking: User toggle button with accessibility labeling for password visibility.
  • 🔒 Sanitized Input Handling: Strips hazardous scripts and tags to mitigate Cross-Site Scripting (XSS).
  • 🔒 Strict HTTPS Redirect: Enforces encrypted TLS 1.3 transport for all authentication payloads.
  • 🔒 Session Persistence: Local state isolation with automatic cleanup on logout.

In-Browser Image Compression

Client-side HTML5 Canvas compression pipeline eliminating server memory bottlenecks.

The Client-Side Pipeline
[User selects 15MB Camera Photo] │ ▼ [FileReader reads raw ArrayBuffer / DataURL] │ ▼ [Image element loads in memory] │ ▼ [Compute aspect ratio: Max 1920x1080] │ ▼ [Draw to HTML5 Canvas 2D Context] │ ▼ [canvas.toDataURL('image/jpeg', 0.85)] │ ▼ [Result: Compressed ~180KB JPEG Payload]

Bandwidth Reduction
  • 🚀 Zero Server CPU Load: Compression runs on the client device GPU/CPU.

  • 🚀 Free Tier Compliance: Bypasses Vercel's 4.5MB serverless payload limit without extra cloud storage costs.
10 // Performance Engineering

Zero-Buffering Architecture

How we eliminated 50-second cold starts and achieved instantaneous tab switching.

❌ Before Optimization
• Render Cold Starts: Sleeping free-tier containers caused a 50–90 second blocking delay.
• Blocking Login Banner: Artificial warming flag prevented users from interacting with the login form.
• 60-Second Fetch Timeout: Hanging network calls locked the browser.
• Skeleton Flashes: Refocusing browser tab triggered full-page skeleton spinners on every click.
✅ After Optimization
• Vercel Edge API: Queries run instantly on Vercel Serverless in < 150ms.
• 0ms Interactive Form: Removed blocking states; inputs are immediately usable.
• 12s In-Memory Cache: GET requests return instantly from RAM with auto-invalidation on write.
• Silent Revalidation: Smooth background updates without jarring skeleton flickers.

17 // Viva Defense

Faculty Q&A Preparation

Structured technical answers to anticipate the evaluation committee's questions.

Q: Why use Serverless over a standard VPS?
Ans: Serverless executes on-demand at edge nodes globally. For neighborhood applications with intermittent traffic peaks (e.g. evening event planning), serverless incurs $0 idle hosting costs while guaranteeing instant scale.
Q: How do you prevent MongoDB connection leaks in lambdas?
Ans: In serverless runtimes, each invocation can create a new connection if unmanaged. We assign the connection promise to global._mongooseCache, allowing warm lambdas to reuse established socket connections.
Q: Why Vanilla CSS over Tailwind?
Ans: Vanilla CSS with native custom properties allows complete aesthetic control, dynamic glassmorphic themes, zero dependency bloat, and a total CSS footprint of only 6.0 kB gzipped.
Q: How does the in-browser image compression work?
Ans: Using HTML5 Canvas, camera photos are decoded in memory, scaled to 1920x1080 bounding box, and re-encoded at 85% JPEG quality. This cuts 20MB files down to under 200KB before transmission.
